# Chapter 7 작업 규칙

<!-- common-rules-version: chapter7-v3 -->

- 현재 Core는 understanding/의 로컬 웹·SQLite 실습이다. 먼저 해당 폴더의 AGENTS.md와 README.md를 읽는다.
- 생성·수정 범위는 understanding/transaction_example.py, sale_example.py, test_examples.py다. 요청받은 실습만 구현한다.
- 계획만 요청받았으면 현재 상태·변경 범위·검사 방법을 보고하고 기다린다. 구현 승인 후 해당 범위만 진행한다.
- legacy-api/·다른 Chapter·기존 ERP·비밀 파일은 수정하지 않는다. reference/를 답안으로 읽거나 복사하지 않는다.
- 웹 서버·추적·제공 검사와 기준 파일은 업무 구현 범위 밖이다.
