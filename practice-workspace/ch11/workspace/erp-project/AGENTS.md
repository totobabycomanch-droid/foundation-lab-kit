# Chapter 11 backend 규칙

- 이 장에서는 `api/main.py` 한 파일로 3층 연결을 학습한다.
- 핵심 저장 규칙은 DB 함수에 두고 API는 호출과 오류 변환에 집중한다.
- `.env.example`만 읽을 수 있으며 실제 `.env`는 읽거나 출력하지 않는다.

- API 입력 검사와 DB의 주문·재고 검사를 구분하고, 성공 응답은 commit 뒤에 반환한다.
- 커밋 중 연결 장애에서는 저장 결과가 미확인일 수 있다. rollback 호출만으로 저장 취소를 보장했다고 설명하지 않는다.
- SQL 실행본·입력 모델·함수 호출·커밋·응답의 순서를 근거로 설명하되 실제 DB 실행은 독자에게 맡긴다.
- 구문·입력 검사는 실제 .env를 읽거나 DB에 접속하지 않는 방식으로 수행한다. 검토를 위해 API 모듈을 그대로 실행해 비밀값을 읽지 않는다.
