# 기초 실습 작업 규칙

## 범위

- 현재 VS Code에서 연 Chapter 폴더 안의 파일만 수정한다.
- 다른 `chXX` 폴더와 `reference-app`은 읽거나 수정하지 않는다.
- 요청받지 않은 완성 코드를 미리 생성하지 않는다.

## 작업 순서

1. 현재 Chapter의 `AGENTS.md`와 `README.md`를 읽는다.
2. 요구사항, 기존 파일, 변경 범위와 검증 방법을 먼저 보고한다.
3. 독자의 승인을 받은 뒤 최소 변경만 적용한다.
4. 변경 파일과 실행한 검증을 `Pass`, `Fail`, `Not Run`으로 구분한다.

## 안전 규칙

- `.env`, 비밀번호, API key, JWT와 실제 DB URL을 읽거나 출력하지 않는다.
- 운영·공용 DB에 SQL을 실행하지 않는다.
- `DROP`, `DELETE`, 폴더 삭제와 이름 변경은 현재 Chapter가 명시한 격리 대상에서만 수행한다.
- 테스트를 실행하지 않았다면 통과로 추정하지 않는다.
