# Chapter 3~11 practice workspace

이 폴더는 전자책 Chapter 3~11의 실습 공간입니다. 한 번에 현재 Chapter 폴더 하나만
VS Code로 엽니다. 다른 Chapter의 결과를 복사하거나 이어서 사용하지 않습니다.

각 폴더의 `AGENTS.md`를 먼저 읽고, 실제 비밀값은 `.env`에만 보관합니다. `.env`는 키트나
Git에 포함하지 않습니다. 실행하지 않은 검증은 `Not Run`으로 기록합니다.

Chapter 3은 `ch03/`의 README를 따라 Python·Node.js를 준비하고 작은 발주 화면을 실행합니다.
정상 저장 뒤 중복 클릭·서버 재전송·회사별 상세 조회를 하나씩 확인합니다.
관찰 장치와 테스트 사용자·조회 데이터는 준비되어 있으며, 생성할 파일은 각 단계의 지침을 따릅니다.

Chapter 4는 `ch04/`에서 같은 도구로 독립된 승인 실습을 실행합니다.
`start_lab.ps1` 하나로 본 실습과 회사 경계 결함 실습을 준비하고 화면에서 공간을 전환합니다.
요구사항 질문, 역할·상태 검사, 회사 경계 추적 순서로 진행하며 앞 장의 코드는 가져오지 않습니다.
초기화는 현재 공간의 데이터·세션만 복원하고 학습자가 구현한 코드는 유지합니다.

Chapter 8은 `ch08/understanding/`에서 Python 3.12 이상과 제공 `start_lab.ps1`을 사용합니다.
`http://127.0.0.1:8308`에서 요청 단가·서버 기준값·수량·VAT를 바꿔 실제 함수 반환값을 비교합니다.
추가 패키지나 DB 준비 없이 업무 코드와 테스트 두 파일을 AI와 완성합니다.
실행·검사·복구의 자세한 순서는 해당 폴더의 README를 따릅니다.

Chapter 11을 마친 뒤에도 이 폴더는 비교·복습용으로 보존합니다. Day 00~30 프로젝트는
`foundation-lab-kit` 밖의 새 폴더에서 시작합니다.

## Chapter 9 화면 검증 실습

practice-workspace/ch09/에서 주문 규칙·실행 예제·테스트 세 파일을 AI와 완성한 뒤
PowerShell에서 ./run.ps1 web을 실행하고 http://127.0.0.1:8309를 엽니다.
Python 3.12 이상과 표준 라이브러리만 사용하며 추가 패키지나 DB는 필요하지 않습니다.
신규 주문의 출고 거부, 정상 진행, 배송 완료 후 재승인 거부, 완료·취소 후 행동 거부와
같은 주문의 전후 상태를 확인합니다. 실행 결과는 복사해 AI 검증에 사용합니다.
주문 구현 전 새 주문 생성의 HTTP 501은 미구현 결과입니다. 원고 9.4 Step 2를 먼저 수행하세요.
파일이 있는데 FileNotFoundError가 나오면 서버를 실행한 키트 경로와 VS Code 폴더가 같은지 확인하세요.
여러 사본의 서버를 동시에 실행하지 말고 코드 수정 후에는 해당 서버를 종료·재시작합니다.
DB 저장·실제 ERP API·동시 요청·멱등성은 이번 실습의 검증 범위가 아닙니다.
자세한 생성·실행·검사·복구 안내는 ch09/README.md와 원고를 따릅니다.
