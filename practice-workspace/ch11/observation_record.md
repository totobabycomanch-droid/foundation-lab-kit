# Chapter 11 관찰 기록

실험 직후 앞의 다섯 행을 직접 채웁니다. 이 파일은 AI에게 수정시키지 않습니다.
비밀값(연결 문자열, 비밀번호)은 적지 않습니다.

- 예상과 같으면 `Pass`, 다르면 `Fail`, 실행하지 않았거나 근거가 부족하면 `Not Run`
- DB 값은 상태 조회 결과를 `주문 상태·재고·원장 건수` 순서로 적습니다. 예: `CREATED·10·0`

| 항목 | 요청 전 DB | 실제 응답·화면 상태 | 요청 후 DB | 판정 |
| :--- | :--- | :--- | :--- | :---: |
| 정상 승인·로딩 잠금 (POST 수, 응답, 버튼 상태) | | | | Not Run |
| 화면의 재고 부족 오류 (400 사유, 오류 표시, 버튼 잠금 해제) | | | | Not Run |
| 같은 화면에서 재시도 (이전 오류 해제, 성공 응답, 화면) | | | | Not Run |
| 수량 0 입력 오류 (422의 qty 오류) | | | | Not Run |
| 잘못된 UUID 입력 오류 (422의 order_id 오류) | | | | Not Run |
