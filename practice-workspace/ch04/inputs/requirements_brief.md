# 요구사항 초안

본사 사용자가 가맹점의 발주 목록을 조회하고 승인할 수 있어야 한다.

## 아직 답이 정해지지 않은 질문

- 본사 직원 중 어떤 역할이 발주 목록을 보고 승인할 수 있는가?
- 본사는 모든 가맹점의 발주를 볼 수 있는가, 담당 가맹점의 발주만 볼 수 있는가?
- 이미 승인한 발주를 다시 승인하면 성공으로 처리하는가, 오류로 처리하는가?
- 승인 상태 변경과 재고 변경 중 하나가 실패하면 두 변경을 모두 취소하는가?
- 정상 승인, 권한이 없는 요청과 잘못된 상태의 요청을 각각 어떤 결과와 테스트로 확인하는가?

위 질문이 전부라고 가정하지 않는다. 이 목록에 없지만 구현 전에 결정해야 할 조건도 찾아본다.
