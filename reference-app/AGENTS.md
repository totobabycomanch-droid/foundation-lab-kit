# Chapter 2~3 reference-app 규칙

- 이 폴더의 애플리케이션은 완성 기준 동작을 조사하는 읽기 전용 스냅숏이다.
- 코드와 SQL을 수정하지 않는다.
- Chapter 3 교차 검증에서는 `review-workspace/ch03/AGENTS.md`가 허용한 결과 Markdown만
  생성하거나 갱신할 수 있다. 템플릿과 예상 판정은 수정하지 않는다.
- 테스트 실행으로 생긴 캐시와 결과 파일은 배포본에 포함하지 않는다.
- `.env`, 토큰, 실제 연결 문자열을 만들거나 출력하지 않는다.
- 실행하지 못한 테스트는 통과로 추정하지 않고 `Not Run`으로 보고한다.
