## 실행 파일 규약

AI는 다음 세 파일을 이 폴더에 생성합니다. 새 키트에는 생성 대상 파일이 없습니다.
먼저 주문 예제와 주문 테스트만 만들고 실행합니다. 판매 예제는 원고 7.5에서 만들며,
기존 주문 테스트를 보존한 채 판매 검사를 추가합니다. 아직 없는 판매 파일을 import하지 마세요.

| 파일 | 역할 |
|---|---|
| transaction_example.py | 중간 확정과 전체 롤백 비교 |
| sale_example.py | 정상 판매·재시도·충돌·재고 부족 |
| test_examples.py | 실제 DB 상태의 자동 검사 |

함수명과 출력 형식은 자유롭게 정해도 됩니다. reference/의 동명 파일은 복구용 참고 자료입니다.
원고의 생성 요청에서는 참고 파일을 읽지 말고 직접 구현하세요.
참고 파일로 복구했더라도 아래 필수 검사를 확인하세요. 테스트 통과 개수만으로 모든 조건을 확인했다고 판단하지 않습니다.

## 필수 검사

- 각 사례의 초기 테이블·재고 데이터를 먼저 준비·확정한 뒤 비교할 거래를 시작한다. 초기 준비와 거래의 경계를 분리해 롤백으로 초기 재고까지 취소되지 않게 한다.
- 연결의 트랜잭션 설정에서 전체 롤백이 실제로 가능한지 확인한다.
  특히 autocommit=True에서는 연결의 commit()·rollback()이 효과가 없으므로, 호출 유무만 보지 말고 저장 실패 뒤 실제 DB 상태로 판정한다.
- 첫 예제: 재고 10·주문 0에서 차감 후 실제 주문 INSERT를 의도적으로 실패시킨다.
  독립 DB에서 중간 확정은 재고 9·주문 0, 같은 트랜잭션은 재고 10·주문 0이다.
- 둘째 예제의 수량은 논리값·문자열을 제외한 양의 정수만 허용한다.
  수량 0·음수·True·문자열 "2"를 각각 거부하고 실제 DB의 판매 행·재고가 요청 전과 같은지 검사한다.
- 상품 A001·재고 5에서 수량 2 판매 후 판매 1건·재고 3이다.
- 동일 키·동일 상품·수량은 같은 판매번호를 반환하고 판매 행과 재고가 그대로다.
- 동일 키·다른 수량은 충돌로 거부하며 판매번호·상품·수량·재고 모두 보존한다.
- 동일 키·다른 상품도 충돌로 거부하며 기존 판매번호·상품·수량·재고 모두 보존한다.
- 별도 초기 DB의 재고 5에서 같은 상품을 서로 다른 키로 2개씩 판매하면 서로 다른 판매번호·판매 2건·재고 1이다.
- 별도 초기 DB의 재고 5에서 정확히 5개 판매하면 새 판매번호·판매 1건·재고 0이다.
- 별도 초기 DB의 수량 6 요청은 판매 0건·재고 5다.
- 요청 키에 DB UNIQUE 또는 PRIMARY KEY 제약을 두고, 변경 SQL에 재고 조건을 넣는다.
- 판매 저장·차감·요청 식별 정보는 같은 트랜잭션으로 처리한다.
- 테스트에서 판매 INSERT를 의도적으로 실패시키고 차감 취소 후 판매 0건·재고 5를 조회한다.
  이어 실패 원인을 제거하고 같은 DB·키·상품·수량 2로 재요청하면 판매번호 생성·판매 1건·재고 3이다.
  실패 장치는 테스트에만 둔다. 테스트용 연결·자원은 실패해도 정리한다.
- 출력 숫자를 직접 적지 말고 실제 DB 조회값을 사용한다. 함수·테스트에 짧은 docstring을 쓴다.

## 실행

Chapter 6에서 만든 ch07/.venv의 Python을 직접 사용합니다. 활성화는 필요하지 않습니다.
실행 파일이 없다면 원고 Chapter 6의 6.2에서 확인하고 기존 환경을 임의로 삭제하지 마세요.

```powershell
& ..\.venv\Scripts\python.exe transaction_example.py
& ..\.venv\Scripts\python.exe sale_example.py
& ..\.venv\Scripts\python.exe -m unittest -v test_examples.py
```

테스트 수보다 필수 검사와 실제 단언문을 확인합니다. 테스트가 0개면 완료가 아닙니다.
예상된 실패는 예제가 처리하며 재실행하면 새 메모리 DB에서 시작합니다. DB 파일을 삭제할 필요가 없습니다.
보고에는 ch07/understanding/test_examples.py와 실제 검색할 테스트 이름을 함께 표시하세요.
