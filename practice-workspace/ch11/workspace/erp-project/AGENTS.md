# Chapter 11 backend 규칙

- [Chapter 11 연결 명세](../../connection_spec.md)와 상위 Chapter 지침의 작업 순서를 먼저 따른다.

- 이 장에서는 `api/main.py` 한 파일로 3층 연결을 학습한다.
- 핵심 저장 규칙은 DB 함수에 두고 API는 호출과 오류 변환에 집중한다.
- 기존 SQLAlchemy·psycopg2 동기 호출에 맞춰 API 경로 함수는 일반 `def`로 작성한다.
- 기존 의존성과 설정을 유지한다. 런타임 연결값은 백엔드 로컬 `.env`의 `DATABASE_URL`을 사용한다.
- `.env.example`만 읽을 수 있으며 실제 `.env`는 읽거나 출력하지 않는다.

- API 입력 검사와 DB의 주문·재고 검사를 구분하고, 성공 응답은 commit 뒤에 반환한다.
- 커밋 중 연결 장애에서는 저장 결과가 미확인일 수 있다. rollback 호출만으로 저장 취소를 보장했다고 설명하지 않는다.
- SQL 실행본·입력 모델·함수 호출·커밋·응답의 순서를 근거로 설명하되 실제 DB 실행은 독자에게 맡긴다.
- 적용 뒤 변경 파일·diff와 구문 검사 결과, 실습을 막는 문제를 보고한다.
- 구문 검사는 API 모듈을 실행하거나 import하지 않고, 실제 `.env`를 읽거나 DB에 접속하지 않는 방식으로 수행한다.
- AI는 HTTP 입력 검사를 실행하지 않고 `Not Run`으로 남긴다. 독자가 원고의 선택 실습에서 직접 확인하며, 입력 검사 구현은 필수로 유지한다.
