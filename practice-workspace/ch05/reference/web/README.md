# 웹 실습 1의 선택 비교 코드

먼저 원고 5.2의 프롬프트로 backend/movement_rules.py와 backend/movement_write.py를 완성합니다.
생성·검증 중 이 폴더를 답안으로 읽거나 자동 복사하지 않습니다.

막혔을 때만 현재 두 파일과 실제 실행 결과를 보관하고 이 두 참고 파일을 비교합니다.
실행해 비교하려면 현재 ch05 폴더를 새 폴더에 복사해 별도로 보관한 뒤, 그 사본의 backend/에
이 폴더의 movement_rules.py와 movement_write.py를 복사하고 start_lab.ps1로 실행합니다.
.venv와 .lab은 복사하지 않고 새 사본에서 준비합니다. 원래 작업 폴더는 유지합니다.
참고 구현의 실행 성공을 자신이 생성한 구현의 성공으로 보고하지 않습니다.

아래 SQL 참고 파일들은 PostgreSQL의 기존 고정 데이터 예제이며 웹 실습의 SQLite DB에 실행하지 않습니다.
