# Chapter 6 시작점

Chapter 7~11과 Day 00 이후 사용할 Python, Node.js, npm과 Docker 상태를 확인하는 공간입니다.
이 폴더에는 실제 비밀값을 만들지 않습니다. 공개 변수 이름은 `.env.tools.example`만 참고합니다.

- Chapter 7 시작 전에는 Python 3.12, ch07/.venv의 Python 3.12와 실행 경로,
  SQLite 조회·unittest import를 확인합니다. ch07의 결과는 원고에 따라 직접 실행해 제공합니다.
- Node.js·npm은 Chapter 11 시작 전, Docker·Compose는 Day 00 시작 전까지 준비합니다.
  Supabase는 Chapter 5 실습 이력을 기록하고 Chapter 10의 준비 절에서 다시 확인합니다.
- environment_report.md에는 `Chapter 7 진입 필수 환경`과 `이후 사용할 환경`을 나눠 기록합니다.
  확인 기준을 통과한 항목은 Ready, 실패·기준 미달 또는 근거가 부족한 항목은 Needs Fix입니다.
  단, 이후 환경 중 설치·확인을 아직 시작하지 않았고 보완 계획이 있으면 Deferred로 구분합니다.
  진입 필수 환경의 미확인·미실행은 Needs Fix이며 Deferred로 미룰 수 없습니다.
- 실패한 항목은 수리를 미뤄도 Needs Fix로 남깁니다. 미완료 항목에는 오류 또는 미착수 사유,
  남은 조치·완료 시점·돌아갈 절을 기록합니다. Chapter 7 진행 가능 여부와 전체 도구 준비 완료는
  구분하며, 진입 필수 환경이 모두 Ready이고 문서 검증·독자 자가 체크를 마치면 Chapter 7로 이동합니다.
