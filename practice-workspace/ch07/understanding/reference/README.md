# 선택 비교와 복구

기본 AI 생성·검증에서는 이 폴더를 답안으로 읽거나 복사하지 않습니다.
먼저 실제 오류와 결과를 보관하고 파일 변경 없이 원인과 최소 보완안을 AI에게 설명하게 하세요.
선택 비교가 필요하면 understanding/을 새 비교 폴더에 복사하되 .lab·캐시는 제외합니다.
선택한 실습의 참고 업무 파일과 테스트를 비교 폴더 최상위의 같은 이름으로 복사하고 원래 서버와 다른 포트로 실행합니다.
참고 구현의 통과를 자신의 AI 생성 성공으로 대신 보고하지 않습니다.
legacy_memory/에는 이전 메모리 DB 예제를 원래 내용으로 보존했습니다. 새 웹 실행 규약과 섞지 않습니다.
