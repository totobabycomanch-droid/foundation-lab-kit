# 막혔을 때 선택하는 비교와 복구

먼저 AI에게 파일 변경 없이 원인과 최소 보완안을 설명하게 하세요. 기본 생성·검증에서는 참고 코드를 읽지 않습니다.
해결이 어려울 때만 현재 ch05 폴더 전체를 새 비교 폴더로 복사합니다. 실행 중인 서버·.lab·.venv·캐시는 복사하지 않습니다.
비교 폴더에서 선택한 실습의 참고 파일만 backend/의 같은 이름 파일로 복사합니다.
- 실습 1: movement_rules.py, movement_write.py
- 실습 2: relationship_write.py, relationship_read.py

다른 포트로 서버를 실행해 원래 결과와 비교합니다. 참고 구현 통과를 자신의 AI 생성 성공으로 보고하지 않습니다.
처음부터 다시 구현하려면 현재 업무 파일을 백업한 뒤 _starter/backend/의 해당 파일을 backend/에 복사합니다.
기반 파일은 기준 배포 ZIP의 새 폴더로 복구하고 직접 작성한 업무 파일은 별도로 보존합니다.
