## 실험과 이해

실행 직후 두 번째 칸을 채우고, 해당 단계의 핵심 코드를 읽은 뒤 세 번째 칸을 한 문장으로 채웁니다.
DB 값은 `주문 상태·재고·원장 건수` 순서이며 정상 승인에서는 원장의 증감량도 적습니다.
코드 위치는 실제 파일과 함수명으로 충분하며, 필요하면 행 번호를 덧붙입니다. AI가 지목한 곳도 직접 열어 확인합니다.
예상과 같고 근거가 있으면 Pass, 다르면 Fail, 미실행·근거 부족은 Not Run입니다.
두 입력 오류의 실행 결과와 판정은 각각 남깁니다. 같은 코드를 확인했다면 위치는 재사용할 수 있습니다.
중간 쓰기 실패 행에는 임시 제약 위반 사유·DB 전후값·제약 제거 성공 여부를 남깁니다.
선택 표시가 없는 일곱 행이 Core 필수 항목입니다. 선택 항목의 미실행은 Core 완료를 막지 않습니다.
키보드·좁은 화면 중 하나만 확인했다면 나머지는 Not Run으로 구분합니다.
