# Chapter 5 참고 SQL

웹 실습 1의 선택 비교는 web/README.md를 따릅니다. 아래 첫 SQL 파일은 기존 PostgreSQL 방식의 참고 자료이며 웹 DB에 실행하지 않습니다. 실습 2의 세 구간은 아래 안내를 그대로 사용합니다.

먼저 AI가 만든 sql/ 파일을 실행하고 본문 SELECT로 결과를 확인합니다.
막혔을 때만 해당 참고 파일을 별도로 실행합니다. 참고 실행은 Core 필수 완료 조건이 아닙니다.

- 01_current_and_history.sql: 파일 전체를 BEGIN부터 COMMIT까지 실행합니다.
- 02_relationship_and_delete.sql: 구간 1 준비 → 구간 2 삭제 시도 → 구간 3 목록 제외 순서로 실행합니다.
  각 시작·끝 주석 사이 전체를 새 쿼리에 복사합니다. 각 구간은 독립된 BEGIN·검사·COMMIT입니다.

전용 실습 DB만 사용합니다. 실습 1 전체와 실습 2 구간 1은 해당 실습 테이블을 초기화합니다.
다른 실습 데이터는 보존하며 COMMIT 후 본문의 SELECT로 조회할 수 있습니다.
실습 2 구간 2·3은 앞 구간의 상태를 검사합니다. 실패하면 필요시 ROLLBACK 후 원인 해결·해당 구간 전체 재실행합니다.
앞 구간에서 확정한 데이터는 남습니다. 완료 구간을 반복하지 말고 처음부터 시작하려면 구간 1을 실행하세요.
같은 테이블을 사용하므로 생성 SQL의 조회 결과를 먼저 기록하고 참고 결과와 구분합니다.
참고 파일의 성공을 자신이 생성한 파일의 성공으로 대신 보고하지 않습니다.
