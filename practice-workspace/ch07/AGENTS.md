# Chapter 7 작업 규칙

<!-- common-rules-version: chapter7-v2 -->

- 개편 Core의 작업 위치는 understanding/이다. 먼저 그 폴더의 AGENTS.md와 README.md를 읽는다.
- 현재 작업 폴더와 생성 파일의 절대 경로를 확인한다. ch07에서 요청받아도 understanding/에 생성한다.
- 기존 API 파일과 legacy-api/는 개편 실습 대상으로 수정하거나 초기화하지 않는다.
- .env와 비밀 값은 읽거나 출력하지 않는다. reference/는 답안으로 읽거나 복사하지 않는다.
