# Chapter 5 — 현재값·이력과 데이터 관계

AI가 두 SQL 예제를 만들고, 독자는 본문의 짧은 SELECT로 현재값·이력과 상품·거래 관계를 조회합니다.
API나 승인 함수를 만드는 실습은 아닙니다.

## 시작과 실행

1. VS Code에서 이 ch05/ 폴더를 엽니다.
2. AI가 AGENTS.md와 README.md, sql/README.md를 읽고 두 파일을 생성하도록 요청합니다.
3. 전용 Supabase SQL Editor에서 사전 확인 후 각 파일을 전체 실행합니다.
4. COMMIT 후 새 쿼리에서 원고의 SELECT를 실행해 업무 결과를 판단합니다.
5. 각 파일을 다시 실행하고 직접 조회 결과가 같은지 확인한 뒤 AI 검증에 전달합니다.

| 생성 파일 | 확인할 결과 |
|---|---|
| sql/01_current_and_history.sql | 현재값 7, 입고 10·출고 -3 두 행과 합계 7 |
| sql/02_relationship_and_delete.sql | 삭제 차단, 목록 0건, 상품·거래 각각 1건과 연결 보존 |

데이터는 ch05_lab의 일반 테이블에 남습니다. 각 파일은 자기 실습 테이블만 초기화합니다.
실습 2는 실습 1의 데이터를 지우지 않습니다. 재실행은 예제를 처음부터 만드는 작업입니다.
공통 이름과 필수 검사는 [sql/README.md](sql/README.md)를 따릅니다.
막혔을 때 별도로 실행할 선택 자료는 [reference/README.md](reference/README.md)를 참고합니다.

참고 파일의 실행 결과를 생성 파일의 결과로 대신 보고하지 않습니다.
참고 SQL을 실행하면 같은 실습 테이블이 초기화되므로 생성 파일의 조회 결과를 먼저 기록하세요.
.archive/와 이전 초기화·리셋 SQL은 이 실습에 사용하지 않습니다.
