# Chapter 11 frontend 규칙

- Vue Options API로 이 장의 단일 화면 연동에 집중한다.
- API 호출 중에는 승인 버튼을 비활성화하고 성공·실패 결과를 화면에 표시한다.
- 오류를 성공 상태로 바꾸거나 실제 비밀값을 코드에 넣지 않는다.
- `package.json`의 의존성을 임의로 최신화하지 않는다.

- HTTP 200과 status=success를 확인한 뒤 완료 상태로 바꾸고, 요청 중 잠금과 성공 후 잠금을 구분한다.
- 응답 없는 오류에는 재요청 전에 DB 처리 결과를 확인하도록 안내한다. 응답 없음만으로 저장 실패를 단정하지 않는다.
- 화면 잠금을 서버의 중복 승인 방지로 설명하지 않는다. 브라우저에서 직접 확인하지 않은 동작은 Not Run이다.
